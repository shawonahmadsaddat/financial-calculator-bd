# Financial Calculator BD v6

Fixed/updated package for GitHub Pages.

- Unified green banking UI
- DPS / Millionaire / Kotipoti method selection
- Advanced Millionaire and Advanced Kotipoti
- EMI amortization schedule
- Four Sanchayapatra schemes
- Bank comparison with Amount + Tenure only
- PWA support
- .nojekyll for GitHub Pages

Bank rates are stored in the app as a prototype internal dataset. They must be maintained from verified official bank/product-rate sources before being presented as live/current rates.
