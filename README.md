# Financial Calculator BD v7

Bank Comparison now uses a verified official-source rate database snapshot dated 2026-09-16.

Banks currently included: Prime Bank PLC, Eastern Bank PLC, Dutch-Bangla Bank PLC, and Bank Asia PLC.

The app deliberately shows — when a current official public source does not provide an exact product/tenure rate, rather than inventing or carrying forward an old rate. Bank rates can change, so the database should be refreshed whenever banks publish revised schedules.
