# Financial Calculator BD v2
Modern mobile-first PWA prototype.

Added:
- Simple + compound interest
- Bank comparison
- Sanchayapatra estimate
- Loan eligibility estimate
- Share result
- Print/PDF workflow
- Professional SVG app icon

Important:
- Bangladesh Bank publishes scheduled-bank deposit/lending rate data; bank rates can change, so the Bank Comparison screen uses user-entered current quoted rates rather than hard-coding stale rates.
- Sanchayapatra profit rates and tax/encashment rules can change. Enter the current official rate applicable to the certificate and purchase date.
- Loan eligibility is only an indicative affordability calculation, not a bank approval decision.
