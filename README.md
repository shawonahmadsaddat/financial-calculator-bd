# Financial Calculator BD v5
Unified professional green banking UI.

Included calculators:
- EMI / Loan + full amortization table
- DPS with simple/compound method selection
- FDR
- Kotipoti and Millionaire goals
- Advanced Millionaire and Advanced Kotipoti
- Bank comparison prototype
- 4 Sanchayapatra types in the requested card style
- Loan eligibility
- Share and Print/PDF workflow
- PWA manifest and professional SVG icon

Important: the calculator prototype contains illustrative rates. Before production, replace them with a maintained, verified product-rate database or official source feed.
